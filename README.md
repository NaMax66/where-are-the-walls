# Where are the walls?

A research journal that began with a simple question about Minoan Crete:

> **Where are the walls?**

Looking at Bronze Age Crete, there is an apparent mismatch: wealthy, highly organized palace centers existed for centuries, yet they do not look like the heavily fortified citadels we expect from later Mycenaean Greece.

Instead of treating that as a curiosity, this project uses it as an entry point into a broader problem:

> **Can we reconstruct a lost system not only from what it built, but from the pattern of functions that disappeared when it collapsed?**

## Working principle

> **The pattern of lost functions is a fingerprint of the destroyed system.**

If a group of functions disappears together after a collapse, that pattern may reveal that they previously depended on the same institutions, infrastructure, specialists, or network connections.

## How we got here

**Where are the walls?**

→ perhaps security did not depend primarily on fortifications

→ what did contemporary states say about Crete?

→ Kaptara / Keftiu

→ Cretan merchants, interpreters, and external communities

→ imported strategic raw materials and high-value production

→ Crete as a potentially specialized maritime and manufacturing node

→ specialization versus autonomy

→ Bronze Age collapse

→ disappearance of functions such as Linear B literacy

→ using post-collapse functional loss to infer pre-collapse dependencies

## Four possible scales

The final center of the project is deliberately unresolved:

1. **Minoan Crete** — the concrete case that started with the walls.
2. **Civilizations** — whether the same method works for other societies.
3. **Systems** — specialization, dependency, redundancy, resilience, and collapse.
4. **The research journey** — how a small anomaly grows into a model, including wrong turns and changes of mind.

## Research discipline

We try to separate four layers:

1. **Evidence** — what primary sources, archaeology, or scholarship actually show.
2. **Inference** — conclusions strongly suggested by the evidence.
3. **Hypothesis** — models that make testable predictions.
4. **Metaphor** — analogies such as Apple, Venice, Taiwan, or AWS that help us think but are not evidence.

Failed hypotheses and changes of mind should remain visible. The evolution of the model is part of the project.

## Repository structure

- `journal/` — chronological research notes and the path of reasoning.
- `hypotheses/` — explicit hypotheses, predictions, counter-evidence, and confidence.
- `evidence/` — source-focused notes.
- `models/` — general system concepts that may extend beyond the Bronze Age.
- `questions.md` — open questions worth testing next.
